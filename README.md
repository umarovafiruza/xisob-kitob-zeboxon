# Oilaviy Expense Tracker (Xarajatlar Nazorati)

Minimalist, zamonaviy va tezkor shaxsiy hamda oilaviy xarajatlarni boshqarish veb-ilovasi.

## Xususiyatlari
- **Minimalist Clean UI**: Ortiqcha bezaklar va og'ir kutubxonalarsiz zamonaviy interfeys.
- **Jami hisoblagich**: Barcha kiritilgan xarajatlarni avtomatik hisoblab borish.
- **Kategoriyalar bo'yicha tahlil**: Oziq-ovqat, Ta'lim, Transport, Kommunal, Kredit va Boshqa toifalar bo'yicha foiz va progress-bar.
- **Xarajatlar tarixi**: Qidiruv, toifalar bo'yicha filtrlash va har bir xarajatni o'chirish imkoniyati.
- **LocalStorage**: Ma'lumotlar brauzer xotirasida avtomatik saqlanib qoladi.
- **Sof texnologiyalar**: HTML5, zamonaviy CSS3 va Vanilla JavaScript.

## Ishga tushirish
Ilovani ishlatish uchun `index.html` yoki `oilaviy_xarajatlar.html` faylini istalgan brauzerda (Chrome, Edge, Safari, Firefox) ochish kifoya.
